# ECONERA grant showcase

The Albanian and English tours are available at `/sq/platform` and `/en/platform`. Start from the World introduction or the Platform link. Both languages expose the same ten stops. Switching languages preserves the current stop. Allow approximately 3–5 minutes.

| Stop | What the evaluator can see |
| --- | --- |
| World and building | The procedural portal, door, interior and masonry wall through links to the existing Albanian experience |
| Material selection | The four-type masonry studio and published catalogue |
| Material listing | A labeled sample lot alongside a link to the public catalogue |
| Procurement project | Planned workspace and purchasing workflow |
| Quotation | A sample supplier response and a link to the authenticated request inbox |
| Logistics and order | A sample delivery workflow and a material subtotal |
| Material passport and AI | Planned capabilities and their purpose |

The tour fixture is a code constant with no database ID, seller, checkout, or creation endpoint. The locale routes perform no Supabase reads or writes. Links to operational features are labeled Albanian and follow their normal publication or authentication rules.

A hosted read-only evaluator deployment can run without Supabase. To demonstrate operational flows, use a separate Supabase project with dedicated accounts, callback settings and storage. No hosted evaluator environment has been provisioned.
